# 05 数组、集合与泛型

## 一页重点速记

| 【重点记住】 | 选择/写法 |
| --- | --- |
| 默认列表 | `List<Task> tasks = new ArrayList<>();` |
| 容器选型 | 数组固定长度；List有顺序可重复；Set去重；Map键值对应 |
| 长度 | 数组length、集合size()、字符串length() |
| 索引 | 从0开始；业务id不是列表索引 |
| 删除重载 | remove(int)按索引；remove(Object)按值 |
| 遍历删除 | 用Iterator.remove/removeIf等，不在增强for中直接改原列表结构 |
| 泛型 | 用T表达可替换的类型；List<Integer>，不能List<int> |
| 复制/视图 | 新ArrayList通常浅复制；subList通常是共享结构的视图 |

**允许查阅：**Set/Map实现差别和泛型通配符；不要使用原始List绕开类型检查。

## 详细图文说明

## 1. 【重点记住】数组与集合怎样选择

| 结构 | 特征 | 常用实现/写法 |
| --- | --- | --- |
| 数组 | 长度固定、索引从0开始，可存基本类型 | int[]、Task[] |
| List | 有顺序，可重复，有索引 | ArrayList |
| Set | 元素按相等规则不重复 | HashSet、LinkedHashSet、TreeSet |
| Map | 键对应值，键唯一，值可重复 | HashMap、LinkedHashMap、TreeMap |
| Queue / Deque，扩展 | 队列/双端队列 | ArrayDeque |

Map不继承Collection。HashSet/HashMap不承诺迭代顺序；LinkedHashSet/LinkedHashMap常用于保留插入顺序；TreeSet/TreeMap按排序规则组织。List有序不代表自动按id排序，是保存元素的顺序。

```java
int[] counts = {1, 2, 3};
int[] zeros = new int[3];
int first = counts[0];
int length = counts.length;

List<String> titles = new ArrayList<>();
int size = titles.size();
```

数组用length字段，集合用size()，字符串用length()。数组索引有效范围0到length-1，越界抛异常。二维数组是数组的数组，各行可以不同长度。

## 2. 【重点记住】List常用API

```java
List<String> titles = new ArrayList<>();
titles.add("Java");
titles.add("SQL");
titles.set(0, "Java 21");
String title = titles.get(0);
boolean exists = titles.contains("SQL");
titles.remove("SQL");
```

| 方法 | 用途 | 注意 |
| --- | --- | --- |
| add(value) | 末尾添加 | 不等于按id保存 |
| add(index, value) | 指定位置插入 | 后续元素位置会移动 |
| get(index) | 按索引读取 | 索引不是业务编号 |
| set(index, value) | 替换已有位置 | 不是追加 |
| remove(index) | 按位置删除 | `List<Integer>`特别容易混淆 |
| remove(object) | 按equals删除首个匹配项 | 找不到通常返回false |
| contains / indexOf | 判断/定位元素 | 使用equals规则 |
| size / isEmpty | 数量/是否空 | null列表不能调用 |
| addAll / clear | 批量添加/清空 | clear会改变原容器 |
| subList(from, to) | 获取区间视图 | 左闭右开；通常共享原列表结构 |
| sort(comparator) | 排序 | 改变当前可变列表 |

```java
List<Integer> ids = new ArrayList<>(List.of(10, 20, 30));
ids.remove(Integer.valueOf(20)); // 删除值20；remove(1)则删除索引1
List<Integer> page = new ArrayList<>(ids.subList(0, 1));
```

List.of创建不可修改列表，不接受null；Arrays.asList得到固定大小、由数组支持的列表，可set但不能随意add/remove；new ArrayList<>(...)才是新的常用可变列表。不可修改不等于其中对象都不可变。

## 3. 【重点记住】遍历与安全删除

```java
for (Task task : tasks) {
    System.out.println(task.getTitle());
}

Iterator<Task> iterator = tasks.iterator();
while (iterator.hasNext()) {
    Task task = iterator.next();
    if (task.isCompleted()) {
        iterator.remove();
    }
}
```

不要在增强for中直接调用原ArrayList的remove；可能引发ConcurrentModificationException或其他遍历问题。常用替代：Iterator.remove、`tasks.removeIf(Task::isCompleted)`，或先收集待删除项再统一处理。removeIf里的方法引用可理解成“把判断行为交给集合执行”。

## 4. 【常用查阅】Set与Map

```java
Set<String> tags = new HashSet<>();
tags.add("java");
tags.add("java"); // 不增加第二个相等元素

Map<Integer, String> titleById = new HashMap<>();
titleById.put(1, "Java");
titleById.put(1, "SQL"); // 相同键替换值
String title = titleById.get(1);
boolean exists = titleById.containsKey(1);
titleById.remove(1);
```

```java
for (Map.Entry<Integer, String> entry : titleById.entrySet()) {
    System.out.println(entry.getKey() + ":" + entry.getValue());
}
```

HashMap.get返回null可能是键不存在，也可能值本来是null；需要区分时用containsKey。getOrDefault在键存在但值为null时仍返回null。HashSet/HashMap的自定义元素/键依赖正确的equals/hashCode；放进去后不要修改参与哈希计算的关键属性。

## 5. 【重点记住】泛型是什么、怎么写

泛型把“元素/数据是什么类型”作为参数传给类或方法，让编译器检查类型，而不是到处使用Object和强制转换。

```java
List<String> titles = new ArrayList<>();
// titles.add(3); // 编译不通过

public class PageResponse<T> {
    private final List<T> items;
    private final long total;

    public PageResponse(List<T> items, long total) {
        this.items = items;
        this.total = total;
    }

    public List<T> getItems() { return items; }
    public long getTotal() { return total; }
}
```

上例为了突出泛型省略page/size，项目中可以包含它们。

```java
PageResponse<String> page = new PageResponse<>(List.of("Java"), 1L);
```

T、E、K、V是类型参数的常见名称，不是特殊关键字。`<>`称为菱形语法，让编译器推断具体类型。类型参数不能用int等基本类型；不要省略成原始类型 `List list`，否则失去有用的编译检查。

### 【常用查阅】泛型方法与边界

```java
public static <T> T first(List<T> values) {
    if (values.isEmpty()) {
        throw new IllegalArgumentException("列表不能为空");
    }
    return values.get(0);
}
```

方法的类型参数 `<T>` 写在返回类型之前。`<T extends Number>`限定T必须是Number或其子类型；extends也用于泛型的接口上界。

### 【扩展参考】通配符

| 类型 | 主要用途 |
| --- | --- |
| List<?> | 元素类型未知；读取为Object，不能随便add具体对象 |
| List<? extends Number> | 读取Number；不能安全加入某个具体数值类型 |
| List<? super Integer> | 可加入Integer；读取通常只能当Object |

List<Integer>不是List<Number>的子类型。常见口诀“生产者extends，消费者super”用于API参数设计，不要求把所有普通变量都写成通配符。运行时泛型大多采用类型擦除，不能直接new T()或写instanceof List<String>。

## 6. 【常用查阅】排序与浅复制

```java
tasks.sort(Comparator.comparingInt(Task::getId));
List<Task> copy = new ArrayList<>(tasks);
```

新列表容器可独立增删，但其中Task通常仍与原列表共享。若API不希望调用方修改内部对象，需要进一步转换成响应对象或复制元素，不是仅复制列表就完成隔离。

## 独立练习：先自己完成，再按标准检查

**练习1：列表删除与去重。** 创建含重复整数的可变列表，删除指定数值而不是指定位置，再安全删除所有负数；最后用适当容器得到不重复结果。

验收：能证明删除的是目标值；遍历修改不引发不正确行为；能说明去重后的顺序是否得到保证。

**练习2：通用容器。** 自行定义一个包含items与total的ResultPage<T>，分别装入字符串列表和任务列表。复制任务列表后，分别做“添加元素”和“修改已有对象字段”的实验。

验收：同一个泛型类适用于两类数据，没有使用原始类型；能解释新容器独立与元素对象共享的区别。

## 工作中先记这些

默认列表先考虑List<T> + ArrayList；编号与索引不同；remove(int)和remove(Object)不同；视图不是独立副本；遍历时正确删除；泛型指定类型，不使用原始List。
